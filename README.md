# Engage 2 Value from Clicks to Conversions

This repository contains a collaborative Kaggle notebook that explores and models the `Engage 2: Value from Clicks to Conversions` competition dataset. The goal is to predict a customer’s purchase value based on their multi-session behavior across digital touchpoints.

## 📌 Competition Objective

Predict the purchase value for each user using anonymized session-level data. The dataset captures user interactions across browsers, traffic sources, devices, and geolocation, enabling modeling of purchase potential and conversion behavior.

## 🧪 Notebook Overview

The notebook performs a full end-to-end analysis and modeling pipeline including:

- Data loading and inspection
- Exploratory Data Analysis (EDA)
- Null value handling and data cleaning
- Feature engineering for categorical and numerical variables
- Target analysis and transformation
- Two-stage modeling strategy:
  - Classification model to predict whether a purchase occurs
  - Regression model to predict purchase value for purchase instances
- Final submission generation

## 🧭 Key Steps

### 1. Data Loading

The notebook loads the provided `train_data.csv` and `test_data.csv` files from the Kaggle competition input.

### 2. Exploratory Data Analysis

- Examines dataset shape and column types
- Identifies high-, medium-, and low-cardinality categorical variables
- Inspects null values, distribution, and feature relationships
- Uses boxplots, distributions, countplots, and correlation matrices

### 3. Data Cleaning

- Replaces anomalous text values like `(not set)` and `unknown` with `NaN`
- Drops columns with >70% missing values
- Converts binary categorical and flag columns to numeric
- Removes zero-variance columns
- Extracts temporal features from the `date` field

### 4. Feature Engineering

- Drops non-informative identifiers like `userId`, `sessionId`, and `sessionStart`
- Groups rare categories in `os` and `trafficSource.medium`
- Simplifies geographic and channel categories
- Creates interaction features such as:
  - `channel_medium`
  - `channel_device`
  - `channel_os`
  - `channel_isMobile`
  - `channel_isWeekend`
  - `channel_bounces`

### 5. Target Analysis

- Target `purchaseValue` is heavily skewed and zero-inflated
- About 79% of values are zero
- The notebook compares raw target distribution with log and Yeo-Johnson transformations

### 6. Two-Stage Modeling Strategy

#### Stage 1: Classification

- Train a classifier to distinguish purchase vs non-purchase
- Uses `XGBClassifier` with a preprocessing pipeline

#### Stage 2: Regression

- Train a regression model only on purchase records
- Uses `XGBRegressor` with a `tweedie` objective and feature transformations
- Includes polynomial feature generation for numeric inputs

## 📈 Model Performance

The notebook compares multiple model options and reports performance metrics:

- XGBoost
- Random Forest Regressor
- LightGBM
- Voting Regressor

Reported metrics include:

- R² score
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- Median Absolute Error

## ✅ Final Submission

The notebook generates a `submission.csv` by:

1. Using the classifier to predict purchase occurrence on test data
2. Using the regression model to generate purchase values for predicted purchase cases
3. Combining results into a final `id` / `target` submission file
